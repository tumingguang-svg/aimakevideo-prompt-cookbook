## 先读哪一页

- **第一次用**：先看 [照片准备](guide/photo-prep.md)，80% 的废片是因为照片不合格
- **想知道花多少钱**：[积分与成本](credits.md)，里面把积分折算成了美元上限
- **想自己写提示词**：[提示词写法拆解](guide/prompt-patterns.md)，有两条能直接填空的骨架
- **想抄现成的**：[文生视频](showcase/text-to-video.md) / [文生图](showcase/text-to-image.md)

## 三个从数据里发现的事实

1. **showcase 里的提示词长度差 8 倍**：动作序列型 189–215 词，风格描述型 26–44 词，都够用。词数取决于你要"一段戏"还是"一张会动的画"。
2. **6 条文生图提示词每一条都带一个 beauty 系定语**（beauty portrait / wabi-sabi beauty / beauty campaign / beauty study / jewelry beauty advertising / lifestyle beauty photography）。
3. **注册赠的 10 积分跑不了任何模板**：最便宜的模板也要 310 积分。免费额度是给 studio 里入门模型用的。

## 数据时效

所有参数、积分、提示词最后核对于 **2026-10-18**。价格和功能会变，下单前以 [定价页](https://aimakevideo.com/pricing) 为准。发现过期，欢迎提 issue。
