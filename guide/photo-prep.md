# 照片准备：13 个模板共用的硬性要求

13 个模板的上传表单里，硬性条件几乎一样。先把这些过一遍，能省掉大部分失败重跑。

## 一、硬性要求（不满足会被拒或出废片）

| 要求 | 说明 |
|---|---|
| **一张照片一个人** | 单图模板（Bulin 47、Rumpelstiltskin、Raindance、Ozil Goal、Thriller Dance）一张照片只能有一个人；合照模板（Hotel Lobby、Migos、Zombie）每人一张，或提供一张双人合照；Grease Dance、Tiny Desk 每人一张 |
| **正脸、脸完全可见** | 侧脸、低头、口罩、墨镜、手挡脸都会影响结果 |
| **成年人** | 页面要求上传者确认照片里的人是成年人 |
| **不是公众人物** | 名人照片不能用来跑 |
| **获得同意** | 上传前必须勾选「我有权使用这些照片，并已获得照片中人物的同意」 |

格式：JPG / PNG / WebP。

## 二、能显著提高成功率的做法

- **光线均匀**：正面顺光或柔和侧光最好。强烈顶光、阴阳脸、背光剪影是最常见的失败原因
- **分辨率够**：人脸在画面里别太小。半身照比全身远景好
- **背景干净**：背景越乱，模型越容易把背景元素混进人物
- **不要过度美颜**：磨皮到五官边界模糊，模型就抓不准脸型
- **同一人多张时保持一致**：双人模板要两个人各自清晰，别一张清楚一张糊

## 三、每个模板额外要注意的

| 模板 | 特别要求 |
|---|---|
| Ozil Goal | 页面建议**从头到脚**、连鞋一起拍进画面 |
| Burning Bridges | 半身或全身都行；宠物和角色也可以 |
| Bulin 47 | 单人、宠物、角色都能用 |
| Stereo Love Funk | 每人一张，**最多 9 张**；也可以只给一张合照 |
| Raindance | 独舞 1 张，双人 2 张 |
| Zombie | 两张：一张人类、一张丧尸 |
| Thriller Dance | 开场是脸部近景，脸最重要；保留自己衣服时拍到腰部以上或全身 |
| Tiny Desk | 主唱必填、最重要；照片里的衣服就是视频里的衣服 |
| Grease Dance | 全景镜头，人在画面里偏小，脸一定要清楚；自定义场景要平视、前面有空地 |

## 四、跑之前先算一下要花多少积分

在 [积分与成本](../credits.md) 里能查到每个模板 480p / 720p 各消耗多少。**先跑 480p 试一条**，确认效果再上 720p，是这个价位下最省的顺序。

## 五、关于"像不像本人"

这类模板都是**固定动作 + 你的照片**的结构：动作、镜头、节奏来自参考片段，照片只提供人物的脸和外形。所以：

- 照片质量直接决定像不像
- 动作和场景不会因为你的照片而改变（这是设计如此，不是缺陷）


## 这些模板都用这份照片要求

- [Bulin 47](../templates/bulin-47.md) —— 1 张照片，正脸完全可见
- [Raindance](../templates/raindance.md) —— 1–2 张照片，独舞或双人
- [Stereo Love Funk](../templates/stereo-love-funk.md) —— 最多 9 张照片，人数越多要求越高
